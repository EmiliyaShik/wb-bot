# 06 - Себестоимость: шаблон Excel, приём файла, хранение

**Требования:** R33, R33.1, R34, R34.1, R35, R143, R158, R168
**Blocked by:** 02, 03
**Зона:** `core/costs.py` · `core/xlsx.py` · `bot/handlers/costs.py`
**Волна:** 3
**Status:** ready

## Что должно заработать

Клиент получает Excel, уже заполненный его собственными артикулами, вписывает себестоимость и отправляет обратно. Бот проверяет и сохраняет.

Ты же делаешь общий помощник по xlsx (`core/xlsx.py`), которым потом пользуются финансовые отчёты и реестр актов. Держи его простым и не завязанным на себестоимость.

## Из брифа, дословно

> «Бот выдаёт Excel-шаблон, заполненный артикулами клиента из Content API: nmId, артикул продавца, название, пустая колонка «себестоимость за единицу».»
>
> «Клиент присылает файл обратно, бот проверяет и сохраняет.»
>
> «Артикулы без себестоимости помечаются в отчётах «нет себестоимости», прибыль по ним не считается.»
>
> «Принимаемые файлы: только xlsx, лимит размера, проверка содержимого.»

## Разделы спецификации

Истории B1-B5, «Хранилище» (таблица costs)

## Критерии приёмки

- [ ] `/costs` ставит задачу в очередь и сразу отвечает «принято, пришлю, когда будет готово»
- [ ] Шаблон xlsx: колонки nmId, артикул продавца, название, «себестоимость за единицу, ₽» (пустая). Артикулы тянутся из `content/v2/get/cards/list` со всеми страницами
- [ ] Уже заполненная себестоимость подставляется в шаблон, чтобы клиент не вбивал её заново
- [ ] Принимается только `.xlsx`, размер не больше лимита из конфига. Другие форматы вежливо отклоняются с объяснением
- [ ] Содержимое проверяется: нужные колонки на месте, значения числовые и неотрицательные
- [ ] Одна кривая строка не отменяет весь файл: хорошие строки сохраняются, по плохим приходит понятный список вида «строка 12: себестоимость не число»
- [ ] Ответ говорит, сколько строк принято, сколько пропущено и почему
- [ ] `costs_for(client_id) -> dict[nmId, Decimal]` и `missing_costs(client_id, nm_ids) -> list[nmId]` для отчётов
- [ ] Деньги считаются в `Decimal`, не во `float`
- [ ] `core/xlsx.py` умеет читать и писать книги с несколькими листами и заголовками, не зная ничего про себестоимость
- [ ] Тесты: правильный файл, файл без колонки, файл с буквами вместо чисел, слишком большой файл, файл не того формата
