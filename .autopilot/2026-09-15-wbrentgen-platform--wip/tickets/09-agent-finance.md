## Что должно заработать

Сердце модуля finance. Забирает детализацию отчёта о реализации, раскладывает неделю по статьям и отдаёт короткую сводку плюс Excel на четыре листа.

**Метод из ТЗ отключён Wildberries 15 июля 2026.** Используется замена: `POST /api/finance/v1/sales-reports/detailed` на `finance-api`, категория токена «Финансы», лимит **1 запрос в минуту** - самый жёсткий в проекте, поэтому год выгружается долго и обязательно через очередь.

Имена полей теперь camelCase, старых snake_case из ТЗ больше не существует. Полная таблица полей и соответствие старым именам - в `wb-api-facts.md` §5.

## Критерии приёмки

- [ ] `/finance` даёт кнопки: последняя неделя, месяц, квартал, год. Сразу «принято, пришлю, когда будет готово», работа идёт через очередь
- [ ] Недельная раскладка: продажи, возвраты, к перечислению, комиссия WB, эквайринг (₽ и %), логистика, хранение, приёмка, штрафы, прочие удержания, СПП
- [ ] Проценты берутся ГОТОВЫМИ полями WB: `commissionPercent` (и `kvw`), `acquiringPercent`, `spp`. К перечислению - из `forPay`. Не пересчитывать
- [ ] Неделя сверяется с агрегатом из `sales-reports/list` (`forPaySum`, `retailAmountSum` и прочие). Расхождение показывается честно, а не прячется
- [ ] Суммы парсятся из строк в `Decimal`, не во `float`
- [ ] Excel: листы «Недели», «Месяцы» (свод недель в месяц), «По артикулам», «Методология»
- [ ] Лист «Методология» для каждой строки называет поле WB и формулу. Не декоративный: по нему должно быть можно проверить руками
- [ ] Повторная выгрузка той же недели ЗАМЕНЯЕТ строки, а не добавляет вторые. Ключ - `reportId` + `rrdId`. Тест: выгрузить неделю дважды, строк столько же
- [ ] Сырые строки сохраняются в `fin_rows`, агрегаты недели в `fin_weeks`: агент 2 и агент 3 работают по базе и в WB не ходят
- [ ] Пагинация по `rrdId` реализована: год выгружается страницами
- [ ] Формулы и список полей дописаны в `CLAUDE.md` между маркерами autopilot
- [ ] Тесты на шве «транспорт» с записанным ответом WB: раскладка, дедупликация недели, пагинация, пустой период
- [ ] В `CLAUDE.md` между маркерами autopilot дописаны: список используемых полей WB с их значением и все формулы финансовой раскладки
