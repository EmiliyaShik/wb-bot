## Что должно заработать

Отвечает на вопрос, который селлер не может посчитать руками: какие артикулы кормят, а какие едят. Складывает данные агента 1, себестоимость и расход рекламы по каждому артикулу.

Расход рекламы берётся из `GET /adv/v3/fullstats` (версия v2 из ТЗ в документации отсутствует), по цепочке `days[] -> apps[] -> nms[].sum`. Ограничения: максимум 50 кампаний и 31 день за запрос, 3 запроса в минуту.

## Из брифа, дословно

> «Источники: данные агента 1, себестоимость из 0.3, расход рекламы по артикулам из Promotion API (fullstats; сверить версию).»
>
> «По каждому артикулу за период: выручка, штуки, себестоимость; комиссия, эквайринг, логистика, хранение, штрафы, реклама, возвраты; чистая прибыль, маржинальность, доля в общей прибыли.»
>
> «Сортировка от самых прибыльных к убыточным. Отдельный блок «убыточные, обезличка, без себестоимости».»
>
> «/profit: топ-5 и антитоп-5 в сообщении плюс Excel.»
>
> «Если себестоимость не загружена, /profit работает и помечает такие артикулы.»

## Разделы спецификации

Истории E10, E10a, E11, B3. Реклама: `wb-api-facts.md` §6

## Критерии приёмки

- [ ] По каждому артикулу за период: выручка, штуки, себестоимость, комиссия, эквайринг, логистика, хранение, штрафы, реклама, возвраты, чистая прибыль, маржинальность, доля в общей прибыли
- [ ] Расход рекламы по артикулу из `adv/v3/fullstats`, суммируется по `days[].apps[].nms[].sum` (артикул там называется `nmId`)
- [ ] Разбиение запросов соблюдено: не больше 50 кампаний и 31 дня за раз, идёт через очередь
- [ ] Нет категории «Продвижение» или `fullstats` недоступен: колонка «реклама» помечается «нет данных», прибыль считается без неё, и в отчёте это написано честно. Не падать
- [ ] Артикулы без себестоимости попадают в блок «нет себестоимости», прибыль по ним НЕ считается. `/profit` при этом работает. Тест это доказывает
- [ ] Отдельный блок «убыточные, обезличка, без себестоимости»
- [ ] Сортировка от самых прибыльных к убыточным
- [ ] `/profit` даёт топ-5 и антитоп-5 в сообщении плюс Excel с полной таблицей
- [ ] Расходы, не привязанные к артикулу, разносятся явным правилом, и правило названо на листе «Методология»
- [ ] Деньги в `Decimal`
- [ ] Тесты: полный набор данных, без себестоимости, без рекламы, убыточный артикул, нулевая выручка
